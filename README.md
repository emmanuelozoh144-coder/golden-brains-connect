# Golden Futures Hub

You are a world-class branding agency, award-winning UI/UX designer, creative director, conversion strategist, copywriter, and senior front-end developer.

Your task is to design and build a premium, modern, responsive website for an NGO called:

# Golden Brains Youth Foundation

This is NOT a donation/payment website.

The primary goal of the website is to build trust, establish credibility, showcase the foundation's mission and impact, and encourage visitors to contact the foundation on WhatsApp if they would like to:

• Support the foundation

• Become a partner

• Volunteer

• Sponsor a project

• Invite the foundation

• Collaborate

• Learn more

Every major CTA throughout the website should ultimately lead visitors to WhatsApp.

DO NOT include payment gateways, donation forms, checkout pages, or payment buttons.

The website should feel like it was designed by an elite global creative agency.

Think:

• Apple

• Stripe

• UNICEF

• Charity: Water

• Google

• Airbnb

The design should be elegant, premium, minimal, modern, sophisticated, clean, highly professional, and emotionally inspiring.

Avoid looking like a generic NGO template.
